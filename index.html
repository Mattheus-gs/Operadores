Operadores Aritméticos

São utilizados para realizar cálculos matemáticos.

Operador Descrição Exemplo
+ Soma 5 + 2 = 7
- Subtração 10 - 3 = 7
* Multiplicação 4 * 2 = 8
/ Divisão 10 / 2 = 5
% Resto da divisão 10 % 3 = 1
** Potência 2 ** 3 = 8 
let numero = 10;

console.log(numero + 5);
console.log(numero * 2);

Operadores de Atribuição

Utilizados para atribuir valores às variáveis.

Operador Exemplo Equivalente
= x = 5 Atribui valor
+= x += 2 x = x + 2
-= x -= 2 x = x - 2
*= x *= 2 x = x * 2
/= x /= 2 x = x / 2 
let pontos = 10;

pontos += 5;

console.log(pontos);

Operadores de Comparação

Comparam valores e retornam true ou false.

Operador Descrição
== Igual
=== Estritamente igual
!= Diferente
!== Estritamente diferente
> Maior que
< Menor que 
console.log(5 == "5");
console.log(5 === "5");

Operadores Lógicos

São utilizados para combinar expressões booleanas.

Operador Descrição
&& E lógico
|| OU lógico
! Negação 
let idade = 20;
let possuiCarteira = true;

console.log(idade >= 18 && possuiCarteira);

Operador Ternário

Uma forma resumida de criar condições. 

condicao ? valorSeTrue : valorSeFalse

let idade = 16;

let resultado =
  idade >= 18 ? "Maior de idade" : "Menor de idade";

console.log(resultado);

Incremento e Decremento

Operador Descrição
++ Incrementa 1
-- Decrementa 1 
let numero = 5;

numero++;

console.log(numero);

Operadores de Tipo

Operador Descrição
typeof Retorna o tipo da variável
instanceof Verifica instância 
console.log(typeof "Olá");
console.log(typeof 10);

Operadores Bitwise

Trabalham diretamente com os bits dos números.

Operador Descrição
& AND
| OR
^ XOR
~ NOT 
console.log(5 & 1);

Spread e Rest (...)

O operador ... pode espalhar elementos ou juntar vários valores. 

const numeros = [1, 2, 3];

const copia = [...numeros];

console.log(copia);

Optional Chaining (?.)

Evita erros ao acessar propriedades inexistentes. 

const usuario = {};

console.log(usuario?.perfil?.nome);

Nullish Coalescing (??)

Define valor padrão apenas para null ou undefined. 

let nome = null;

console.log(nome ?? "Visitante");
